DISCORD INTERACTIVE CONTROL PANEL

The Discord control panel is owner-DM only. No Guild ID or Channel ID is required.

When you DM /panel, the bot shows dropdown menus like a ticket panel:

1. Select a bot
2. Select a category
3. Select an action

Categories:
- Bot Management
- Economy
- Minecraft
- Logs & Information

Common Minecraft actions are selectable. Custom Minecraft commands open a Discord modal so you do not need to type slash commands into Discord.

Examples of selectable actions:
- Start Autosell
- Stop Autosell
- Reconnect
- Status
- Check Balance
- Enable/Disable Auto-Pay
- AFK ON/OFF
- /spawn
- /home
- /balance
- Custom Command
- View Recent Logs
- Full Status
- Refresh

The owner-only restriction is based on Owner User ID. Server/guild interactions are rejected.
